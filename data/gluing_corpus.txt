# Gluing package corpus. One entry per line, colon-delimited, no spaces.
# Blank lines and lines starting with # are ignored.
#
# Run with check_gluing.m from the repo root:
#   magma -b [tags:=tag1,tag2] [line:=<entry>] [oracle:=1] check_gluing.m
# Batch: parallel -a data/gluing_corpus.txt magma -b line:={} check_gluing.m
# oracle:=1 is a temporary flag (until Genus2Gluings exists) that calls
# Genus2Elliptic2/3 + CanonicalGluingList directly instead.
#
# Line format:
#   tag:field:E1:E2:n:count:proof:curves
#
# tag    one of bhls2, bhls3, lmfdb, empty, iso, eq, cm, pp, composite, nf, regress.
# field  0 for Q, else the defining-polynomial coefficients of K (ascending).
# E1,E2  a-invariant lists; over K each a-invariant is itself a coefficient
#        list on the power basis.
# n      level (glue along full n-torsion).
# count  expected number of returned curves; -1 = do not check.
# proof  expected info`proof ("certified", "traces-only"); "-" = do not check
#        (always "-" for oracle-mode entries, which carry no certificate).
# curves expected canonical output: a list of [fcoeffs,hcoeffs] pairs
#        (ascending coefficients, y^2 + h(x)y = f(x), data/README.md
#        conventions); [] for expected-empty; [-1] = do not check.
#
